三步接入

从注册到第一次调用

  1. 01

    在 控制台 注册并创建一枚 API 密钥。

  2. 02

    把客户端的 Base URL 填成 https://ai.lu-k.cn/v1，密钥填上一步生成的。

  3. 03

    模型名填 deepseek/deepseek-v4.1-flash，直接开始对话。
